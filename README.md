# Nuri Al-Taie — Official Profile

Static RTL Arabic profile page for Nuri Al-Taie.

## Publish
Upload these files to a GitHub Pages repository. GitHub Pages can host static HTML/CSS/JS directly from a repository.

Before publishing, replace `YOUR-DOMAIN.example` in `index.html`, `robots.txt`, and `sitemap.xml` with the final domain.

## SEO
After the site is live:
1. Verify the site in Google Search Console.
2. Submit `/sitemap.xml`.
3. Keep the canonical URL consistent.
4. Add only official social/profile URLs you control.
